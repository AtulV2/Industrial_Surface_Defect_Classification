# 📁 Outputs Directory

## Why This Directory Exists
In machine learning engineering, it is standard practice to separate:
1. **Source code** (`src/`) — logic and application code.
2. **Datasets** (`data/`) — raw and augmented training/validation images.
3. **Model weights** (`models/`) — compiled binary neural network artifacts (`.keras`).
4. **Generated artifacts & diagnostics** (`outputs/`) — visual reports, evaluation plots, and sample explainability outputs generated during model training and verification.

Keeping outputs in a dedicated directory ensures that runs do not clutter source code or model folders and allows teams to inspect diagnostic artifacts at a glance.

---

## What Is Stored Here

| File | Generated By | Purpose |
|---|---|---|
| `training_history.png` | `src/train.py` | Accuracy and loss curves across training epochs (used to monitor convergence, overfitting, and validation performance). |
| `gradcam_sample_crazing.bmp` | `src/gradcam.py` | Visual proof artifact showing a sample test image (left) alongside its Grad-CAM attention heatmap (right) for automated verification. |

Any future evaluation reports (confusion matrices, ROC curves, batch predictions) should also be saved to this folder.
